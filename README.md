# TipShare

TipShare is a modern, intuitive, and feature-rich Tip Calculator and Bill Splitter app for Android, built entirely with Jetpack Compose and Kotlin. 

Whether you're dining out with friends or splitting expenses, TipShare makes it effortless to calculate tips and divide bills fairly. 

## ✨ Features

* **Quick Calculation:** Easily input bill amounts and instantly see tip and total values.
* **Bill Splitting:** Divide the total bill among any number of people with quick preset options.
* **Custom & Preset Tips:** Choose from quick tip percentage presets or define a custom tip amount.
* **Multi-Currency Support:** Switch between different currencies seamlessly.
* **History:** Automatically saves your past calculations. View, restore, or clear your history at any time.
* **Customization & Settings:**
  * **Themes:** Support for Light, Dark, and System Default themes.
  * **Dynamic Color:** Material You dynamic color support (Android 12+).
  * **Haptics & Animations:** Toggle haptic feedback and UI animations.
  * **Defaults:** Set your default currency, tip percentage, and number of people for faster calculations.
* **Modern UI:** Built with Jetpack Compose following Material 3 design guidelines.

## 🛠️ Tech Stack

* **Kotlin:** 100% Kotlin.
* **Jetpack Compose:** Declarative UI toolkit for building native Android UIs.
* **Material 3:** Modern design system for Android.
* **Navigation Compose:** For seamless navigation between screens (Home, History, Settings, About).
* **ViewModel & StateFlow:** Robust state management and reactive UI updates.

## 🚀 Getting Started

To build and run the app locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/abdullah-ateeq/TipShare.git
   ```
2. Open the project in **Android Studio**.
3. Sync the Gradle project.
4. Run the app on an emulator or a physical device.
